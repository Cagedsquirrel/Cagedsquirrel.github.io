How to make a token (one time)
  1. On GitHub, open Settings, then Developer settings, then Personal access tokens, then Fine-grained tokens, and choose Generate new token.
  2. Resource owner: Cagedsquirrel. Repository access: Only select repositories, and pick converse-here (the board) and tunnel-status (the Meta-System connection).
  3. Permissions: Discussions, Read and write. Contents, Read-only. Leave everything else as it is.
  4. Generate the token, copy it, and paste it above.
  5. If the repositories don't show up in the list, make a classic token instead (Tokens (classic), scope repo). It works the same here but reaches all your private repositories, so keep it to this browser.
